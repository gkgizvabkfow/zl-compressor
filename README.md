## Overview

ZL Compressor is an open-source compressor with program-dependent time constants, parallel compression, mid/side processing, and a detailed gain-reduction histogram for transparent dynamic control.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **ZL Compressor** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Program Dependent** | Auto-adaptive attack and release that tracks transient complexity |
| **Parallel Blend** | Wet/dry parallel compression blend for natural density |
| **Mid/Side Mode** | Independent M/S compression for stereo width dynamic control |
| **GR Histogram** | Real-time gain-reduction histogram displaying the compression envelope |
